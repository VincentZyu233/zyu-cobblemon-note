## 原版挖矿路线

铜矿在 `Y=-16` 到 `Y=112` 出现，常规地下采矿推荐 `Y=48` 附近；滴水石洞穴会生成特别密集的铜矿，是最舒服的补货地点。

::: tip 前期储量
看见铜不要只拿一组就走。它同时会被基础球、PC、治疗机和 TM Machine 消耗，建议基地箱子长期留至少两组铜锭。
:::

## Cobblemon 的优先用途

| 阶段 | 物品 | 铜的作用 |
| --- | --- | --- |
| 开局 | 精灵球 | 铜是第一阶球材；`4 红球果 + 1 铜锭`合成 4 个精灵球 |
| 早期 | PC | 需要 2 铜锭和 4 铁锭，是管理队伍与电脑仓库的核心 |
| 中期 | 治疗机 | 需要 3 铜锭；治疗整队比长期喝药更省资源 |
| 中期 | TM Machine | 需要 2 铜锭；开始制作和写入 TM 的设备 |
| 以后 | 广角镜、对焦镜等 | 一些命中相关持有物会消耗铜锭 |

::: info 当前最实用的顺序
铜不够时，优先保证“精灵球补给 -> PC -> 治疗机 -> TM Machine”。不要在刚开荒就把所有铜做成建筑方块。
:::

## 采集与存放

- 使用石镐或更高等级工具采矿，原版时运可提高原矿掉落收益。
- 生铜块建议带回基地后再统一熔炼，铜锭按“球材/机器”单独放箱。
- 铜块会氧化变色，适合建筑；用于 Cobblemon 配方的仍是铜锭，别误把全部铜锭压成建筑块。
