这张图不是原版紫水晶洞，而是 Cobblemon 1.8 的**属性宝石矿脉**。它可产出电之宝石，用于属性宝石携带物和 TM 制作。

## 图里的三个方块

| 东西 | 外观与作用 | 该怎么处理 |
| --- | --- | --- |
| 深层水晶母岩 | 深板岩质感的生长核心，物品 ID 为 `cobblemon:deepslate_crystal_core` | 用正确工具挖走，带回基地；它会掉落自身 |
| 电之宝石块 | 图中大块绿蓝色立方体，是整座矿脉的“种源” | 至少留下 1 块和母岩相邻，别全敲掉 |
| 电之宝石簇 | 附在宝石块表面的尖刺，有小、中、大和成熟四阶段 | 等成熟后采收，产出电之宝石 |

::: tip 名称看着“绿色”并不代表草系
截图的悬浮信息已经确认它是**电之宝石块**。Cobblemon 当前 `zh_cn.json` 中电与草的两个方块名称键有对调痕迹，遇到名称与颜色不一致时，以 JEI/EMI 的物品 ID 或悬浮信息为准。
:::

## 这处矿脉该怎么挖

1. 先找到并挖走**深层水晶母岩**，不要拿空手或低级工具硬挖。
2. 优先等尖刺状的宝石簇长到最大，再用镐采；成熟簇通常掉 `2-4` 个电之宝石，时运有机会额外加 1 个。
3. 想保留矿脉外观，用精准采集挖宝石簇；否则直接采宝石更划算。
4. 大方块不要急着全部采完。至少保留一块，才能让母岩在基地继续生成同属性的簇。

::: warning 小阶段不要急着敲
第 0 阶几乎没有掉落，第 1 阶只掉 1 个；第 2 阶掉 `1-2` 个。等到完整大簇再采才合算。
:::

## 基地培育法

将母岩与一块同属性宝石块直接贴住，周围留空气：

```text
[深层水晶母岩][电之宝石块] [空气]
                 [空气]
```

母岩会随机刻检查相邻的宝石块，在空位生成对应属性的宝石簇；簇长满后可转化成新的宝石块，并继续向外生长。源码的实际连通上限为**母岩加约 6 块宝石块**，达到上限后仍会出现成熟簇，但不会继续复制出新宝石块。

若朋友只有母岩、没有任何电之宝石块：先采够 **4 个电之宝石**，在工作台摆成 `2 x 2`，合成一块电之宝石块，再贴到母岩旁。母岩单独摆着不会凭空选择或产生宝石。

::: tip 要让它继续生长
随机刻只会在加载中的区块发生。把它放基地、在附近活动即可；不必供电，也不要求深板岩环境或黑暗环境。
:::

## 宝石做什么

- **战斗**：让宝可梦携带对应属性宝石。使用对应属性的招式时会消耗它，得到一次性威力强化。
- **TM 工坊**：Cobblemon 1.8 的 TM 配方会消耗属性宝石；拥有会相应招式的宝可梦后，才能解锁那些 TM 配方。
- **继续培育**：4 个同属性宝石合成 1 个宝石块，作为母岩农场的种源。

## 源码依据

- `TypeGemFeature.kt`：地下生成时会随机选 18 种属性之一，放置母岩、首个宝石块并触发生长。
- `TypeGemCoreBlock.kt`：母岩随机刻生长、连通上限和相邻空气条件。
- `TypeGemClusterBlock.kt` 与 `loot_table/blocks/electric_gem_cluster.json`：四阶段成长以及成熟簇的掉落。
- `recipe/electric_gem_block.json`：4 个电之宝石合成 1 个电之宝石块。
