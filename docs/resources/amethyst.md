## 去哪里找

紫水晶洞是原版稀有结构，不是普通矿脉。它能生成在 `Y=-58` 到 `Y=30`，所以挖深板岩矿洞、探索大型洞穴时都有机会遇到；没有一个像钻石那样的“最高效固定 Y 层”。发现后务必记下坐标。

::: tip 核心判断
看见无法获得、表面会长出紫晶芽的**芽生紫水晶**，就找到了可再生的母块。不要挖它，也不要把相邻六个面贴满方块。
:::

## 怎样长期收获

芽生紫水晶会在相邻空气面依次长出小型、中型、大型紫晶芽，最后成为紫水晶簇。收成熟簇只会移除簇，母块仍在原处，之后会继续长，因此紫水晶碎片可再生。

1. 插火把并封住洞口，防止采集时被怪打断。
2. 挖走普通紫水晶块、方解石、凝灰岩时，避开芽生紫水晶。
3. 想要材料就用时运镐采成熟簇；精准采集会拿到完整簇，适合装饰。
4. 先囤 `16-32` 个紫水晶碎片，再考虑大规模建筑。

::: warning 不可搬迁
芽生紫水晶没有可获得物品，精准采集也带不走。要做基地农场只能保护原洞并修通道路，不能把母块搬回家。
:::

## Cobblemon 用途

| 优先级 | 物品 | 紫水晶用途 |
| --- | --- | --- |
| 高 | 空白 TM | `2 碎片 + 2 玻璃` 合成 2 张，是 TM 体系的基础耗材 |
| 高 | TM Machine | 需要原版有色玻璃，而有色玻璃需要紫水晶碎片 |
| 中 | 图鉴 | 可作为图鉴配方中的“屏幕”材料 |
| 中 | 经验分享器 | 需要 2 碎片，适合培养刚抓到的新成员 |
| 中 | 进化奇石 | `4 碎片 + 不变石`；给仍可进化的宝可梦携带可提高双防 |
| 后期 | 镜类、特性护具、化石分析仪 | 都会消耗紫水晶碎片，按队伍需求再做 |

::: details 洞里的其他方块
**凝灰岩**可与岩石宝石制作硬石头，给岩石系招式增伤；方解石当前没有重要的直接合成需求，留一两组建筑即可。它们也可用于 Habitat 编辑器的环境布置，但这不是前期生存刚需。
:::
