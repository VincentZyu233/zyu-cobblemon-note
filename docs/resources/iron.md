## 原版挖矿路线

常规矿洞挖铁以 `Y=16` 附近最稳定；若附近有高山，`Y=80` 以上会重新变多，约 `Y=232` 最密集，常可直接在山体表面看到。前期开洞时走 `Y=16`，有高山再改为爬山采露天铁。

::: tip 不要只按原版工具需求备铁
做完铁甲和铁镐后，Cobblemon 仍会持续吃铁：球、PC、治疗机、经验分享器和不少持有物都会用到。建议长期保留至少两组铁锭。
:::

## Cobblemon 的优先用途

| 阶段 | 物品 | 铁的作用 |
| --- | --- | --- |
| 捕获升级 | 超级球与第二阶功能球 | 铁是第二阶球材；例如超级球一次产出 4 个 |
| 队伍管理 | PC | 需要 4 铁锭，避免队伍满员后无处整理 |
| 续航 | 治疗机 | 需要 4 铁锭，配合活力块可治疗整队 |
| 培养 | 经验分享器 | 需要铁锭和铁头盔，后期带新人更舒服 |
| 后期 | 连接绳、进化道具、持有物 | 多种进化与战斗物品会消耗铁 |

::: warning 铁与精灵球不要混算
要做超级球时，先确认自己留下了 PC、治疗机所需的铁。球果够多而铁不够时，宁可先做少量针对性的球，也不要一口气耗光全部库存。
:::
