## 原版挖矿路线

钻石矿在 `Y=-64` 到 `Y=16` 出现，越深总体越多。实用分支挖矿高度是 `Y=-54`：已经接近高产区，又比 `Y=-59` 更容易处理岩浆和基岩。务必使用铁镐或更高等级工具；时运 III 再挖大矿脉收益最高。

::: warning 先别急着做持有物
前期钻石优先级是钻石镐、附魔台与备用装备。没有稳定生存工具链前，不要因为一个战斗道具把钻石库存清空。
:::

## Cobblemon 的优先用途

| 阶段 | 物品 | 钻石的作用 |
| --- | --- | --- |
| 中后期 | 特性护具 | 需要钻石、铁盾和紫水晶；保护携带者的特性不被改变、消除或无视 |
| 中后期 | 清净坠饰 | 需要钻石、金、线和紫水晶，用于对战中的能力变化防护 |
| 中后期 | 若干战斗持有物 | 依具体配方消耗钻石，先确认队伍定位再做 |
| 原版 | 附魔、装备、工具 | 仍是探索与采矿效率的基础 |

::: details 什么时候开始花钻石做 Cobblemon 道具
建议至少拥有钻石镐、附魔台和一套备用钻石之后，再开始制作特性护具等专用物品。小服普通探索时，这些道具不是必需品；面对 Alpha 或计划对战队时再投入更划算。
:::
