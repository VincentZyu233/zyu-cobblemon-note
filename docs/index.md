## 先做两件事

1. 客户端直接导入本整合包的 `.mrpack`，不要从服务端 `mods` 文件夹手动拼客户端。客户端内含地图、优化和视觉模组，服务端并不需要全部安装。
2. 在单人游戏中找找是否有 `Tutorial World v4 (1.8)`。整合包内置了这个教学存档，适合先熟悉界面和基础交互；没有出现也不影响多人游玩。

::: tip 这个包的核心体验
Cobblemon 不要求你立刻刷满图鉴。把每次外出设成一个小目标，例如“带回两种新属性”“找一株新颜色球果”“扫完一片海岸”，会比盲目跑图更有意思。
:::

## 推荐的推进节奏

| 阶段 | 你该完成什么 | 先别急着做什么 |
| --- | --- | --- |
| 第一天 | 御三家、床、食物、石铁工具、第一批球果 | 独自硬打高等级或 Alpha 宝可梦 |
| 前三天 | 球果园、几颗基础球、图鉴、3 到 4 只队员 | 为了稀有宝可梦把地图跑得太远 |
| 一周内 | 六人队、治疗机、PC、球果园与常用物资农场 | 只练一只宝可梦 |
| 中期 | 队伍平均等级、关键升级招、属性宝石与 TM Machine | 把所有稀有材料马上花光 |
| 后期 | Alpha 狩猎、完整队伍、道馆或赛事 | 单人垄断关键地点 |
