三蜜蜂不是普通的虫/飞行系收藏品。它能像原版蜜蜂一样授粉并给蜂箱加蜜；其中稀少的雌性还能在 `Lv.21` 进化为蜂女王，成为基地最稳定的蜂蜜瓶来源。

::: tip 一句话结论
见到三蜜蜂先抓、立刻看性别。**雌性必留并练到 Lv.21；雄性留 1-2 只做蜂场授粉助手；多余个体才考虑击败。**
:::

## 为什么雌性最重要

三蜜蜂的雌性比例只有 `12.5%`，雄性则为 `87.5%`。打开宝可梦摘要或看队伍栏的性别符号确认即可，不必只凭模型外观猜。

雌性三蜜蜂在 `Lv.21` 升级时进化为蜂女王；雄性永远不会进化。该进化在数据中还保证产出一件 `Shed Shell` 类持有物。

| 个体 | 推荐处理 | 长期价值 |
| --- | --- | --- |
| 雌性三蜜蜂 | 收服、练到 Lv.21 | 蜂女王，直接产蜂蜜瓶 |
| 雄性三蜜蜂 | 留 1-2 只 | 授粉、蜂箱产蜜、肩扛陪伴 |
| 多余雄性 | 随意 | 图鉴外价值有限 |
| 野外蜂女王 | 优先收服 | 直接跳过练级，立刻做蜂蜜栏 |

三蜜蜂也是可肩扛宝可梦。选中后在空地按 `R` 放出，它可作为小型跟随伙伴；肩扛与蜂场资源用途互不冲突。

## 两种蜂蜜路线

### 路线 A：蜂女王直接装瓶

这是最省心的基地材料线：

1. 把蜂女王放进[牧场](/ranch)的封顶蜂栏。
2. 手持玻璃瓶，对蜂女王右键。
3. 获得 `1` 瓶蜂蜜；该交互冷却为 `18,000` 游戏刻，约 `15 分钟`。

蜂蜜瓶可在[营火锅](/machines/campfire-pot)中与万能粉制作活力碎片，再推进为活力块和[治疗仪](/machines/healing-machine)。

::: warning 要先收服成自己的
玻璃瓶交互要求目标是你拥有的蜂女王。野生蜂女王或朋友的蜂女王不能当成你的取蜜机；多人基地应各自放牧，或先按约定完成宝可梦转让。
:::

### 路线 B：三蜜蜂给原版蜂箱加蜜

三蜜蜂带有 `pokemon_bee` AI：晴天白天会在附近花朵采蜜，采蜜完成后寻找原版蜂箱并进入，像原版蜜蜂一样推进蜂箱的蜂蜜等级。蜂箱满级时，用玻璃瓶右键蜂箱可得到蜂蜜瓶。

最低建设条件：

```text
封顶围栏内：花朵 x 多种 + 原版蜂箱 x 1~2 + 三蜜蜂 x 1~2
```

- 放多种花，蜂箱放在三蜜蜂可到达的位置。
- 保持白天、晴天；雨天或夜晚三蜜蜂会倾向进入蜂箱。
- 三蜜蜂会飞，栏位必须封顶；灯光与围栏照常做好，防止怪物进入。
- 这条路线产的是**蜂箱里的蜂蜜等级**，不是直接对三蜜蜂右键取蜂蜜。

::: tip 有蜂女王后仍值得留三蜜蜂
蜂女王适合定时稳定取瓶；三蜜蜂蜂场适合让原版蜂箱持续工作。二者共用花园、蜂箱和玻璃瓶，可以并存。
:::

## 在哪里找

当前世界生成数据中，三蜜蜂通常在白天、无雨、天空光照 `8-15` 的温带与主世界环境生成，等级约 `1-24`。附近存在原版蜂箱时，它的生成权重会提高 `5 倍`；主世界的花朵和蜜露树也会构成合适的生成环境。

因此想找第一只时，去有花的晴天草地或森林边缘，自己先放一个蜂箱也有帮助。使用宝可梦零食时，源码还会将其常规生成权重额外提高 `5 倍`。

## 打死还是收服

三蜜蜂击败后可能掉 `0-1` 蜂蜜瓶、`0-1` 蜂巢，另有各 `2.5%` 概率获得毒针或抗岩果。作为一次性补给可以接受，但不适合作为主要蜂蜜来源。

优先级应为：

1. 先收服一只雌性，或直接收服蜂女王。
2. 保留一到两只雄性做蜂箱授粉。
3. 有了稳定蜂场后，多余三蜜蜂才按需要击败取素材。

蜂女王本身防御与特防都是 `102`，会学回复指令、守住指令和攻击指令，可作为偏耐久的虫/飞行系；但速度只有 `40`，并且被岩石系四倍克制。它的主要价值依然是资源线，而不是替代你的主力输出。

## 不会自动繁殖

三蜜蜂和蜂女王可以被牧场长期保存、放出和互动，但当前 Cobblemon 1.8 没有官方孵蛋/宝可梦繁殖实现。把两只三蜜蜂放在一起不会新增幼体；蜂场的“养殖”指的是授粉与蜂蜜循环，不是繁殖数量。
