# 同行、肩扛与坐骑

Cobblemon 1.8 将“放出来跟随”“肩膀伙伴”和“骑乘”分别建模。能跟随不代表能骑；看起来很大也不保证能飞。最可靠的判断是放出后实际右键测试，并在摘要和游戏内提示确认。

## 同行：所有队员的基础操作

1. 用 `↑` / `↓` 选择左侧同行栏中的队员。
2. 准星指向空地，按 `R` 放出当前选中的宝可梦；它会跟随你。
3. 再按 `R` 收回。准星对野生宝可梦按 `R` 则会以当前选中队员发起战斗。

左侧栏没有显示时，按 `O` 切回。“隐藏同行宝可梦栏”在 1.8 源码的默认键位就是 `O`；`M` 的界面与此无关。

## 肩扛伙伴

部分小型宝可梦的物种数据标记为 `shoulderMountable: true`，满足条件时会落在玩家肩上。它是外观与陪伴互动，不消耗队伍位，也不是骑乘。

比较容易遇到的肩扛候选包括：皮丘/皮卡丘系、伊布系、帕奇利兹、咩利羊幼体、部分小型鸟和小型哺乳类。不同姿态、体型、是否已放出及服务器配置都会影响是否可上肩，遇到想留的就放出来走一段测试。

::: tip 肩膀与跟随并不冲突
先让它作为同行宝可梦放出；若该物种和当前状态支持肩扛，游戏会处理位置。无法肩扛时，它仍然会正常跟随。
:::

## 陆地坐骑

可骑物种会在源码中定义 `LAND` 行为、座位和速度/跳跃/耐力等属性。你刚遇到的**圈圈熊**就是确认可用的陆地坐骑，源码有 `LAND: horse` 骑乘行为与一个座位。

值得留意的陆地坐骑方向：

- 坐骑小羊 / 坐骑山羊：前期最自然的跑图选择。
- 泥驴仔 / 重泥挽马、烈焰马、肯泰罗、重型熊类：更偏长距离陆地探索。
- 圈圈熊：抓到后可兼任强力一般系与坐骑。

### 正确上坐骑：`Shift + 右键`，再点互动转盘

对**自己拥有**的坐骑，直接右键并不会上去。这是正常行为：源码会把普通右键优先留给交付携带物、饰品等交互。正确步骤如下：

1. 将坐骑放入随身队伍，选中它后朝平地按 `R` 放出。
2. 靠近它，按住 `Shift` 再右键，打开宝可梦互动转盘。
3. 选择转盘**左侧的马鞍图标**，悬停提示为“骑乘”。
4. 成功后用 `WASD` 移动、`Space` 跳跃；再次选中同一只并按 `R` 可安全离乘。

::: tip 为什么直接右键不行
`PokemonEntity.mobInteract` 只有在玩家按住 `Shift` 时才会调用互动转盘。转盘的 `RIDE` 选项才会向服务器发送骑乘请求，随后服务器执行 `startRiding`。因此“右键没上去”通常不是模组坏了，而是少了 `Shift` 或没点转盘里的马鞍。
:::

如果转盘内的马鞍图标是灰色或根本没有，检查：该宝可梦必须是你的、已从队伍放出的实体、未参与战斗、未被拴住或放在展示/平台状态，且个体尺寸不得低于服务器的最小骑乘比例（本包默认 `0.75`）。

### 坐骑山羊与重泥挽马

两者都定义了 `LAND: cobblemon:land/horse` 骑乘行为和一个座位：

| 坐骑 | 更适合的事 | 源码骑乘能力范围 |
| --- | --- | --- |
| 坐骑山羊 | 跑图、翻坡、短途探索 | 加速 65-75；跳跃 40-60；速度 45-65；耐力 45-65 |
| 重泥挽马 | 长距离稳定赶路 | 加速 50-70；跳跃 30-40；速度 30-40；耐力 70-100 |

两只都属于陆地坐骑，不会飞，也不具备水上骑行行为。第一次请在平地测试；重泥挽马耐力更高，但不适合拿来跳崖。

### 用粉色球果汁永久提高速度

骑乘速度是每只宝可梦单独生成的骑乘属性，不随等级、努力值或战斗面板里的“速度”自动成长。想让某一只坐骑跑得更快，要用**球果汁**直接强化它。

| 球果汁 | 固有骑乘属性效果 | 适合对象 |
| --- | --- | --- |
| 粉色球果汁 | 速度 `+2`，加速 `-1` | 优先给坐骑山羊；重泥挽马也可补速度 |
| 红色球果汁 | 加速 `+2`，耐力 `-1` | 起步慢、想更快提速时使用 |
| 黄色球果汁 | 耐力 `+2`，操控 `-1` | 重泥挽马等长距离坐骑 |
| 绿色球果汁 | 跳跃 `+2`，速度 `-1` | 翻山和跳跃用途，不适合追求跑图速度 |

粉色球果汁的基础材料是：`粉色球果 + PP草 + 元气根`，在[营火锅](/machines/campfire-pot)中合成。

| 粉色球果 | PP草 | 元气根 | 营火锅 |
| :---: | :---: | :---: | :---: |
| <img src="/assets/movement/pink-apricorn.png" alt="粉色球果" width="72" style="image-rendering: pixelated;" /> | <img src="/assets/movement/pep-up-flower.png" alt="PP草" width="72" style="image-rendering: pixelated;" /> | <img src="/assets/movement/energy-root.png" alt="元气根" width="72" style="image-rendering: pixelated;" /> | <img src="/assets/movement/pink-campfire-pot.png" alt="粉色营火锅" width="72" style="image-rendering: pixelated;" /> |

前三格放进营火锅的食材栏；营火锅本身是加工设备，不会被消耗。颜色不同的营火锅功能相同，粉色只是和本配方的球果颜色相呼应。

如果想专门堆速度，在锅的 3 个调味料格放入带**甜味**的调料。源码将甜味对应为 `SPEED`：甜味总值达到 `15 / 35 / 45 / 55 / 75 / 105` 时，分别额外提供 `1 / 2 / 3 / 4 / 5 / 6` 点速度。最终产物的物品提示会显示实际获得的骑乘强化；以 JEI 和成品提示为准，不要盲目消耗材料。

### 甜味调料：放树果，不是放糖

营火锅的这三个格子只接受**树果**（源码筛选标签是 `#cobblemon:berries`），并累计各树果的隐藏口味值。坐骑速度只读取其中的 `SWEET`（甜味）数值；**糖、甜浆果，以及名字里带“甜”的糖饰，都不算骑乘甜味调料**。

::: tip 最省心的纯速度配方
有 **3 个芒芒果（Mago Berry）** 时，三个调味料格全放芒芒果：总甜味 `45`，额外速度 `+3`。配合粉色球果汁的固有速度 `+2`，成品会给目标坐骑速度 `+5`、加速度 `-1`；实际数值仍会受该物种的速度上限限制。
:::

| 树果 | 每个甜味 | 额外口味 | 三格怎么用 | 适合度 |
| --- | ---: | --- | --- | --- |
| 桃桃果（Pecha） | 10 | 无 | 放 2-3 个都只有速度 `+1` | 前期最容易试出效果 |
| 芒芒果（Mago） | 15 | 无 | 3 个合计 45，速度 `+3` | **最干净的常用速度配方** |
| 释陀果（Custap） | 40 | 苦 10 | 1 个已速度 `+2`；3 个速度 `+6`、跳跃 `+1` | 强，但树果较稀有 |
| 莓榴果（Watmel） | 30 | 苦 10 | 2 个速度 `+4`、跳跃 `+1` | 强力的中后期选择 |
| 洛玫果（Roseli） | 25 | 苦 10 | 3 个速度 `+5`、跳跃 `+1` | 速度与跳跃兼顾 |
| 卡希果（Kasib） | 20 | 涩 10 | 3 个速度 `+4`、操控 `+1` | 想同时改善操控时用 |
| 乐芭果（Magost） | 20 | 苦 10 | 3 个速度 `+4`、跳跃 `+1` | 卡希果的跳跃取向替代 |

同一种口味会相加，不同口味会**分别**结算。例如三个释陀果总计甜味 `120`、苦味 `30`，因此会分别生成速度 `+6` 和跳跃 `+1`，并非二选一。物品提示里的“骑乘强化”会直接显示最终结算结果。

::: warning 不要被名称误导
甜蜜糖饰（草莓糖饰、爱心糖饰等）用于霜奶仙相关进化；它们的调味料数据没有 `SWEET` 数值。原版甜浆果也不是 Cobblemon 树果，不能用来给球果汁加速度。JEI 中查看树果提示，出现“甜味”数值的才是有效材料。
:::

做完后，主手拿球果汁，对已放出的目标坐骑右键使用。强化会永久写入这只宝可梦的数据，不是一次性的冲刺药；但每项属性都有该物种的上限，满了后继续使用不会再增长。

::: tip 你的两只怎么投
坐骑山羊初始速度范围为 `45-65`，最多还能补 `20` 点，因此优先喂粉色球果汁最划算。重泥挽马初始速度仅 `30-40`，速度成长空间只有 `10` 点，适合当高耐力坐骑；想纯跑图时优先骑山羊。
:::

::: warning 先确认自己在冲刺
两只都支持冲刺。只按 `W` 是慢走；按住冲刺键或双击前进进入冲刺后，才会调用骑乘速度上限。若骑乘时不冲刺，再高的速度属性也不会完全体现。
:::

## 水上与飞行坐骑

水上和飞行同样依赖物种是否提供对应的骑乘行为，而不是属性标签。水系不等于能水上骑，飞行系也不等于能带人飞。

- **水上候选**：拉普拉斯、乘龙、暴鲤龙、吼吼鲸/吼鲸王等大型水生宝可梦。
- **飞行候选**：喷火龙、比雕、七夕青鸟、钢铠鸦、快龙等大型飞行宝可梦。

先在基地旁的低空或浅水测试，确认当前物种、形态和服务器版本已经启用该行为；飞行中切勿在高空盲目离乘。1.8 提供“启用在飞行中离乘”的配置，关闭时只允许在地面下坐骑。

::: warning 不要靠猜测跳崖
飞行坐骑尚未验证前，按它不能飞处理。先在平地放出、右键骑乘、短距离移动；确认有飞行控制后再过悬崖或海面。
:::

## 源码依据

- `PokemonEntity.mobInteract`、`showInteractionWheel`：自己拥有的宝可梦须 `Shift + 右键` 打开互动转盘；其 `RIDE` 项才发起骑乘。
- `InteractWheelGuiFactory.kt`：骑乘选项固定在互动转盘左侧，使用马鞍图标。
- `PartySendBinding.kt`：`R` 负责放出/收回，并在骑乘时发送离乘请求。
- `HidePartyBinding.kt`、`PartyOverlay.kt`：`O` 切换同行栏显示。
- `species/generation2/ursaring.json`：圈圈熊具有陆地骑乘行为和座位。
- 物种 JSON 的 `shoulderMountable`、`riding` 字段：分别控制肩扛和陆地/水上/飞行行为。
