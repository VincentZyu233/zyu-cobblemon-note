# 抓捕与图鉴

## 精灵球不是自动捕获按钮

把精灵球拿在主手，瞄准野生宝可梦后投掷。即使在战斗界面里选择“捕获”，也仍然需要自己拿球、瞄准和投出。投偏的球会掉在地上，可以捡回；捕获失败的球则会消耗。

前期基础球足够抓队员。等资源稳定后再按照目标选择球种：

| 场景 | 值得准备的球 |
| --- | --- |
| 普通探索 | Poké Ball / Great Ball |
| 高价值目标 | Ultra Ball |
| 战斗第一回合 | Quick Ball |
| 夜间与阴暗处 | Dusk Ball |
| 水中目标 | Dive Ball |
| 已捕获过的物种 | Repeat Ball |
| 很重的宝可梦 | Heavy Ball |

精灵球的加成条件和倍率都能在游戏内物品提示或官方 Wiki 查到。不要把所有材料只做成一种球。

## 图鉴是探索导航

图鉴可以扫描野生宝可梦，也会在战斗和成功捕获时更新记录。它能查看属性、特性、掉落、体型、基础种族值等信息；先扫描再决定要不要追，效率很高。

推荐习惯：

1. 第一次见到的新物种，先扫描。
2. 见到喜欢但暂时抓不了的目标，记下所在生物群系和时间。
3. 每次外出设定图鉴目标，例如新增 5 个“见过”或 2 个“捕获”。
4. 不要只收藏同一属性，队伍的覆盖面比重复强度更重要。

## 队伍养成原则

野外捕到的宝可梦都能成为队员。早期最实际的提升是让队伍等级接近、招式属性不重复、能互相补位。一个等级很高的主力加五只低等级成员，会让之后的探索和战斗变难。

在一只宝可梦进化、学到新招或加入主队前，打开摘要页确认它承担的职责：输出、耐久、速度、异常状态、属性补盲，至少要占一项。
