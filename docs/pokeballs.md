精灵球的共同基础是：目标血量越低越好；睡眠和冰冻通常优于麻痹、灼伤、中毒。特殊球是在这个基础上额外叠加场景修正，并不是无视血量的万能球。

::: tip 球果资料入口
球果树的外观、生长阶段、获取与种植细节，可交叉查阅 [Cobblemon Wiki：Apricorn](https://wiki.cobblemon.com/index.php/Apricorn)。本文的配方与倍率仍以本服的 Cobblemon `1.8.0+1.21.1` 实际数据为准。
:::

::: tip 一句话选球
开局第一回合用先机球；夜晚/洞穴用黑暗球；水/虫用捕网球；重型目标用沉重球；低等级目标用巢穴球；已经抓过的物种用重复球；拖到后期用计时球。
:::

::: tip 黑暗球别只看 MiniHUD 的 `block`
MiniHUD 的 `Light Level Numbers = block` 显示的是**方块光照**：火把、萤石等方块发出的光。白天露天草原没有发光方块时显示 `0` 完全正常，但这不表示该处在游戏判定中是黑暗。

Cobblemon 的黑暗球源码实际读取 `entity.level().getMaxLocalRawBrightness(...)`，即该格的**局部原始亮度最大值**。它会综合天空光和方块光：白天露天通常有天空光 `15`，所以即使 MiniHUD 的 `block = 0`，黑暗球依然是 `x1`；只有综合亮度为 `0` 才是 `x3.5`，为 `1~7` 才是 `x3`。

所以 MiniHUD 的 `block` 数字适合检查基地是否有怪物生成风险，却不能单独用来判断黑暗球。抓怪时优先选择深洞、被实心方块完整遮住天空的暗处；夜间露天的数值还会随天空变暗而变化，不应仅凭白天地上的 `0` 投黑暗球。

你的客户端已安装 **MiniHUD 0.32.60**。可通过 MaLiLib 配置界面（本地全局绑定为 `A + C`，冲突时在“选项 -> 控制”改键）启用 **MiniHUD -> Renderer Toggles -> Light Level Overlay**；建议在 **Renderer Hotkeys -> overlayLightLevel** 设置一键开关。Tweakeroo 不是这个光照显示功能的主力。
:::

## 合成读法与材料等级

除特别标明者外，球果配方都一次产出 **4 个**。九宫格固定读法为：

```text
      上球果
左球果  中心材料  右球果
      下球果
```

中心材料等级：**T1 铜锭、T2 铁锭、T3 金锭、T4 钻石**。因此下表把四个球果按“上 / 左右 / 下”压缩写法列出，例如 `黑 / 蓝蓝 / 黑，铁` 就是上黑、左右蓝、下黑，中心铁锭。

::: tip 月亮球：肉眼、F3 与 MiniHUD 怎么判断
**肉眼最直观：** 晚上抬头看月亮。完整圆盘是满月（`x4`）；接近完整的凸月是 `x2.5`；半月是 `x1.5`；细月牙和完全看不见的新月都是 `x1`。云层、洞穴和下界都会让肉眼判断失效。

**F3：** Java 版调试屏的 `Local Difficulty` 行末会显示 `Day N`。用 `N mod 8` 查表：`0` 满月 `x4`，`1/7` 凸月 `x2.5`，`2/6` 半月 `x1.5`，`3/4/5` 为 `x1`。这是不依赖额外 HUD 的精确办法。

**MiniHUD：** 按 `A + C` 打开 MaLiLib 配置，进入 **MiniHUD -> Info Toggles**，启用 `World Time Formatted`（源码键名 `infoWorldTimeFormatted`）。再到 **Generic -> Date format Minecraft**，填入 `第 {DAY_1} 天 {HOUR}:{MIN} | 月相：{MOON}`。MiniHUD 源码会按世界日数 `day % 8` 直接显示 Full moon、Waning gibbous、Last quarter 等八种月相，不需要自己算余数。

::: warning Cobblemon 1.8 的实际代码与物品提示不完全一致
物品提示和代码注释都写“只在夜间增加”。但本服实际安装的 `Cobblemon-fabric-1.8.0+1.21.1.jar` 与公开 1.8 源码实现检查的是 `gameTime`，不是每日循环的 `dayTime`：仅在世界总时间 `12000~24000` 的首个夜晚强制 `x1`；世界运行超过这段后，月相倍率会在**白天也参与计算**。因此当前版本最可靠的实战判断是月相本身，而非“是不是晚上”。后续模组版本若修正为 `dayTime`，再恢复为只在夜间投月亮球。
:::
:::

## 古代球：不是更强的“普通球”

古代球配方使用 Tumblestone（普通、天空、黑色）替换了现代球的大部分侧面球果。它们有 `ancient` 标记，投掷手感也不同。

| 古代球 | 中心等级与侧料 | 捕获与投掷特点 |
| --- | --- | --- |
| 古代精灵 / 碧蓝 / 柑橘 / 翠绿 / 玫瑰 / 板岩 / 象牙球 | 铜 + 普通 Tumblestone | 都是 `x1` 的古代基础球。 |
| 古代超级球 | 铁 + 普通 Tumblestone | `x1.5`。 |
| 古代高级球 | 金 + 普通 Tumblestone | `x2`。 |
| 古代沉重球 | 铜 + 黑色 Tumblestone | `x1`，但投掷力度仅 `0.75`；名字不代表现代沉重球的重量加成。 |
| 古代铅球 | 铁 + 黑色 Tumblestone | `x1.5`，投掷力度 `0.75`。 |
| 古代巨重球 | 金 + 黑色 Tumblestone | `x2`，投掷力度 `0.75`。 |
| 古代羽毛球 | 铜 + 天空 Tumblestone | `x1`，投掷力度 `2.5`。 |
| 古代飞翼球 | 铁 + 天空 Tumblestone | `x1.5`，投掷力度 `2.5`。 |
| 古代喷射球 | 金 + 天空 Tumblestone | `x2`，投掷力度 `2.5`。 |
| 起源球 | 无普通合成配方 | 保证捕获的古代稀有球。 |

古代配方的球果颜色仍对应名称：碧蓝=蓝、柑橘=黄、翠绿=绿、玫瑰=粉、板岩/沉重/铅/巨重=黑；羽毛/飞翼/喷射则以蓝、白球果搭配天空 Tumblestone。它们用于遗迹与收藏路线，开荒优先级低于现代特殊球。

## 甜蜜球：条件球的上限

<img src="/assets/pokeballs/love_ball.png" class="ball-hero" alt="甜蜜球">

甜蜜球不是“粉色所以适合爱情宝可梦”的装饰球，它检查的是**本场战斗中已出战过的己方宝可梦**与野生目标的物种和性别：

| 战斗条件 | 捕获率 |
| --- | --- |
| 己方没有异性目标，或目标无性别 | `x1` |
| 有一只与目标性别相异的已出战宝可梦，但不同种族/家族 | `x2.5` |
| 有一只与目标**同一种族**、且性别相异的已出战宝可梦 | `x8` |

例如你想抓一只雌性毛辫羊：先让自己的雄性毛辫羊出战一次，再换人压血、睡眠、最后投甜蜜球，就能达到 `x8`。双方都是无性别、同性，或你只有不同物种的队员时，甜蜜球没有特殊价值。

配方每次出 4 个：上方白球果，左/右/下各粉球果，中心为三阶球材料。它需要不少粉球果和白球果，因此不要拿它当日常通用球。

::: warning 关键是“已出战过”
源码检查的是战斗参与者，而不是电脑仓库、牧场或单纯放在队伍栏里却从未上场的宝可梦。为吃到倍率，先把符合条件的异性宝可梦派上场一回合。
:::

## 治愈球：远征补给球

<img src="/assets/pokeballs/heal_ball.png" class="ball-hero" alt="治愈球">

治愈球的捕获率固定是 **`x1`**，与普通精灵球相同。它不会让难抓的目标更容易进球；其价值是**一旦抓到成功**，新成员会立刻：

- 回复全部 HP；
- 清除异常状态；
- 回复全部招式 PP。

因此它适用于“这只抓到就要直接上场”的远征情景，例如队伍刚缺水系、抓到泳圈鼬或其他临时补位队员，又离基地治疗机很远。若是抓来进电脑、牧场展示或之后再练，优先用捕获倍率更高的球。

配方每次出 4 个：上/下粉球果，左/右白球果，中心是一阶球材料。粉白球果足够时，出远门带 2~4 个治愈球即可。

## 其他附带效果的球

- **友友球**：成功捕获后把亲密度设为 `150`，适合计划走亲密度进化的伙伴。
- **豪华球**：之后获得亲密度的正向增长翻倍，适合长期主力。
- **月亮球**：随月相改变效果，适合夜间主题玩法，但不如黑暗球稳定。
- **等级球**：按己方与目标等级关系判断；己方等级优势越大越好。
- **诱饵球**：适合钓鱼相关场景；**狩猎球/园庆球**有专门场景，日常开荒不如通用球。

## 球果材料怎么规划

你手上常见的绿、蓝、粉、黑球果，不要全部压成同一球种。

| 你遇到的材料 | 优先做什么 | 原因 |
| --- | --- | --- |
| 绿球果 | 巢穴球、友友球、黑暗球 | 前期低等级捕获和亲密度路线都有价值。 |
| 蓝球果 | 沉重球、捕网球、潜水球 | 能覆盖重型、水中、水/虫三类明确场景。 |
| 黑球果 | 沉重球、黑暗球、高级球 | 圈圈熊等重型目标与夜间抓捕都能消耗。 |
| 粉球果 | 治愈球、甜蜜球 | 治愈球更实用；甜蜜球需要特定性别与物种关系。 |

::: warning 别忘了球也要命中
在战斗中选“捕获”后，仍需手持对应球瞄准目标投出。投偏、落地的球可以捡回；命中但捕获失败才会消耗。
:::

## 你的下一次外出推荐组合

带 `4 巢穴球 + 4 沉重球 + 4 黑暗球 + 4 普通/超级球`。遇到圈圈熊走沉重球路线；夜洞里的未知目标先黑暗球；低等级新成员用巢穴球。这样不会被单一条件卡住。
