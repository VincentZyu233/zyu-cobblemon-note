# 树果肥料：种植、增产与变异

Cobblemon 的肥料是一套专门服务于**树果树**的系统。它不是给所有农作物通用的骨粉替代品：小麦、胡萝卜、PP 草、活力蕾、复活草和球果树都不会从这些肥料获得效果。

::: tip 先给结论
前期只做两种就够：想尽快收成用 **速速肥**，想囤树果、做料理或钓鱼饵用 **硕果肥**。其余土质肥要配合某颗树果的偏好，吃惊肥则是冲稀有树果变异的工具。
:::

## 怎么制作

先在工作台合成 `3 个肥料`：

```text
骨粉（或其他标记为“肥料”的物品）+ 腐肉 + 泥土 + 纸
```

再用一份肥料和下列材料无序合成对应类型：

| 成品 | 额外材料 | 源码中的实际效果 |
| --- | --- | --- |
| 速速肥 | 任意 `c:fertilizers` 肥料，通常直接用骨粉 | 生长计时器减半；效果共消耗 5 次成长阶段 |
| 硕果肥 | 烈焰粉 | 每次采收额外 `1-2` 个树果；共生效 5 次收成 |
| 吃惊肥 | 闪烁的西瓜片 | 与相邻树果发生变异时，判定率从 12.5% 提升至 50%；共 3 次判定 |
| 壤土肥 | 泥土 | 成为部分树果的偏好土质 |
| 粗糙肥 | 砂土 | 成为部分树果的偏好土质 |
| 湿湿肥 | 泥巴 | 成为部分树果的偏好土质 |
| 泥炭肥 | 苔藓块 | 成为部分树果的偏好土质 |
| 沙土肥 | 沙子 | 成为部分树果的偏好土质 |

::: info 为什么会有很多“土质肥”
每种树果都在自己的数据中写了 `favoriteMulches`。树果原本会根据群系、天气等条件拿到额外产量；用了它偏好的肥料后，即使基地环境不满足相应条件，也能补上那一项产量加成。

因此土质肥不是“所有树果都加产量”。要养特定树果时，再在 JEI 中查它的树或查本页末尾源码说明即可。
:::

## 如何施肥

1. 用锄头把一格泥土变成**原版耕地**；树果不种在普通泥土上。
2. 主手拿任意一颗树果，对着耕地顶面右键。树果本身就是种植材料，会变成幼苗。
3. 等它还是幼苗或生长阶段时，主手拿肥料，对着**树果树本体**右键。
4. 出现骨粉粒子并消耗一份肥料，就说明成功。成熟后正常右键采收；树不会因采收消失。

只能对尚未开花的树果树施加一层肥料。同一棵树已有肥料、已经开花或成熟后，不能叠加或替换，先收成并进入下一轮再施。

::: warning 不要对错目标浪费
球果树可直接使用原版骨粉催熟，但**不接受这九种树果肥料**。PP 草、活力蕾和复活草也不在 `Mulchable` 方块实现范围内；它们的量产路线和树果肥料无关。普通泥土、沙子和陶瓦是野外树果树的自然生成底材，不是玩家人工种植的有效土壤。
:::

## 三个最实用的方案

### 1. 急着做球果汁的树果调料：速速肥

速速肥把树果从幼苗到结果、以及采收后的再结果计时器都缩短为原来一半。它很适合你刚拿到一两颗有甜味、辣味等用途树果，想尽快建立存货的阶段。

它不是永久效果。源码给它 5 次持续次数，每次进入新的成长计时会减少一次；到期后这棵树回到正常速度。

### 2. 想长期囤货：硕果肥

硕果肥不加快生长，而是在采收结算时额外给 `1-2` 个树果，最多不会超过这棵树枝头实际可结的数量。它适合已经稳定成熟、且你会反复收成的常用树果。

### 3. 想解锁新品种：吃惊肥

树果树在生长时可与附近兼容的另一种树果发生变异。吃惊肥将每次有效变异判定从源码基础的 `125 / 1000` 提升到 `500 / 1000`。先在 JEI 找到目标树果的“树果变异”配方，再按它给出的两种亲本相邻种下；不是随机把任意两棵树摆一起就一定有结果。

## 对你当前基地的建议

- 想做坐骑球果汁：先种能提供所需口味的树果，给最先成熟的一棵上**速速肥**。
- 想做大量宝诱饵、料理、药品：先保证基础树果数量，再给反复收成的那棵上**硕果肥**。
- 刚开荒不用特意做土质肥和吃惊肥；烈焰粉、闪烁的西瓜片更值得先留给地狱与治疗资源线。

## 源码依据

- `item/MulchItem.kt`：肥料右键时只会作用于实现 `Mulchable` 的方块，并在成功后消耗一份。
- `block/BerryBlock.kt`、`block/entity/BerryBlockEntity.kt`：仅树果树实现施肥，速速肥将计时器乘以 `0.5`。
- `api/berry/Berry.kt`：硕果肥每次额外 `1-2` 个树果；偏好肥料会补齐未满足的环境产量条件。
- `block/BerryBlock.kt`：吃惊肥将变异阈值由 `125/1000` 放大 4 倍。
- `recipe/*_mulch.json`：本页全部合成材料。
