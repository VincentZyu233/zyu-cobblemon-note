# 专题：寻找与收服皮卡丘

皮卡丘在 Cobblemon 1.8 中是可自然生成、可肩扛的电属性伙伴。它不是坐骑，但速度高，早期就有电击、蹭蹭脸颊和电磁波等实用招式；抓到后可用雷之石进化为雷丘。

::: tip 本页数据来源
本页按本整合包的 Cobblemon 1.8 源码 `0025_pikachu.json` 与 `pikachu.json` 整理。与其他版本、旧 Wiki 或附加数据包的生成地点不一致时，以本包实际服务器为准。
:::

## 去哪里找

普通皮卡丘的自然生成条件很明确：

| 条件 | 本包设定 |
| --- | --- |
| 地点 | 主世界的森林标签生物群系 |
| 位置 | 地面生成 |
| 天空光照 | 8-15，优先白天或明亮开阔处 |
| 普通个体等级 | Lv.16-32 |
| 稀有度桶 | `uncommon`，不是随处可见 |
| 雷暴加成 | 权重 5 倍 |
| 宝点心加成 | 权重 2 倍 |

森林中还能遇到皮卡丘群：群体最高 4 只，常见的皮卡丘个体约 Lv.19-29；也可能混有皮丘或极少数雷丘。看到一只时，先环顾附近树林，不要立刻离开。

::: warning 不要在黑暗森林里硬等
它要求天空光照至少 8。夜晚、密林树冠下或洞穴里都不合适。白天走森林边缘、林间空地和能看见天空的位置，效率更高；遇到雷暴则值得专门巡一圈。
:::

## 出发前准备

- 带数个普通精灵球或高级球。皮卡丘源码捕获率为 `190`，不属于最难抓的目标；它残血后普通球也有机会，想稳一点就带高级球。
- 带一只不会一击打倒它的低威力队员。你的低等级草系、虫系、钢系或非本系普通招式通常更好控血；不要上来就用高等级地面系强攻。
- 有能施加异常状态的队员更好。睡眠最稳，麻痹也能减少它的行动压力。
- 下雨雷暴天再去森林，既符合生成条件，也能拿到 5 倍权重加成。

## 收服流程

1. 在明亮森林见到皮卡丘后，先用图鉴扫描，确认等级和附近是否还有群体成员。
2. 用等级接近、低威力的招式将其压到黄血或红血。皮卡丘耐久不高，尤其避免地面系招式，地面对纯电属性效果绝佳，很容易直接打倒。
3. 有机会就施加睡眠或麻痹；没有也不必硬等，先压血量更重要。
4. 在战斗里选择捕获，拿着精灵球瞄准投掷。第一次不成功就继续投，不要为了多打一回合而把它打昏。
5. 成功后从队伍栏选中它，朝空地按 `R` 放出。皮卡丘的物种数据有 `shoulderMountable: true`，满足状态时可以作为肩扛伙伴同行。

::: danger 两个最常见失误
不要把皮卡丘当成可骑坐骑，它是肩扛伙伴而不是陆地坐骑；也不要对它使用地面系招式控血。后者是克制攻击，特别容易把它直接打倒。
:::

## 抓到以后怎么玩

皮卡丘基础速度为 90，适合先手补盲和施加异常。升级可学到电磁波（Lv.4）、电球（Lv.12）、电火花（Lv.20）、放电（Lv.32）和十万伏特（Lv.36）。

它在源码中可以对雷之石进行物品交互进化：在队伍里选中皮卡丘，手持雷之石对它使用，通常会进化为关都雷丘。若处在阿罗拉区域偏置生物群系，则会得到阿罗拉雷丘；因此想保留普通雷丘时，不要在热带岛屿等区域随意进化。

::: tip 进化前别急
如果你更想要肩扛伙伴或喜欢皮卡丘外观，可以先不进化。进化是一次确定选择；等队伍确实缺电系输出、并确认所在地形后再用雷之石。
:::
