# 实战：收服圈圈熊

圈圈熊是很值得挑战的重型一般系：攻击高、耐久不差，后续还能在特定条件下进化为月月熊。它的攻击种族值有 `130`，所以即使你现在已有高等级主力，也不能把它当作普通小怪硬打。

::: tip 这次的核心思路
先让己方活下来，再将圈圈熊压到红血并附加睡眠，最后投沉重球。大根茎负责延长吸血续航；元气根只在关键时刻急救，不能复活昏厥成员。
:::

## 本次队伍与职责

这份流程按当前队伍编写：**妙蛙草 Lv.20 / 重泥挽马 Lv.43 / 火炎狮 Lv.51 / 电电虫 Lv.29 / 坐骑山羊 Lv.39 / 肯泰罗 Lv.42**。

| 队员 | 对圈圈熊的任务 | 不要做什么 |
| --- | --- | --- |
| 妙蛙草 Lv.20 | 首发使用催眠粉；若已学寄生种子，也可在睡着后补上持续消耗。 | 它等级低，催眠成功后就换下，别留下来硬吃高威力物攻。 |
| 重泥挽马 Lv.43 | 第一后备坦克，负责承受圈圈熊攻击、争取换人和投药回合。 | 招式若伤害很高，目标进黄血后就停手。 |
| 火炎狮 Lv.51 | 等级最高，适合作为兜底或在己方被压制时换入。 | 火系招式和高威力招容易把红血目标误击倒，后段不要用。 |
| 电电虫 Lv.29 | 目标已经睡着且血量仍高时，可用较弱招式小幅压血。 | 等级和耐久较低，别让它正面扛圈圈熊。 |
| 坐骑山羊 Lv.39 | 有回复、寄生或低威力草系招式时，是稳健的消耗位。 | 草系并不克制一般系，别因为属性颜色而盲目强攻。 |
| 肯泰罗 Lv.42 | 必要时抗一轮并收尾换人。 | 同为一般系，通常没有属性优势；物攻高时尤其要防止误杀。 |

::: tip 先看招式，不要死背名单
圈圈熊是**一般系**，你当前队伍没有天然克制它的格斗系主力。打开摘要确认每只的实际招式后，选择威力较低、命中稳定的一招压血；“不一击打死”比属性相克更重要。
:::

## 出门前检查

| 物品或队员 | 这次如何使用 |
| --- | --- |
| 沉重球 | 首选。圈圈熊源码重量为 `125.8 kg`，沉重球属于高档重量加成目标。至少带 4 个。 |
| 大根茎 | 给会用吸取 HP 招式的队员携带，例如有吸取招式的草系。它不消耗，只增强回复量。 |
| 元气根 | 放快捷栏，战斗中给**尚未昏厥**、但已危险的出战成员使用；回复 80 HP，亲密度 -10。 |
| 普通/高级球 | 沉重球用完后的备选，别因只带一类球而中断。 |
| 床、食物、方块 | 先设重生点，避免失败后跑尸和夜怪同时干扰。 |

### 沉重球配方

一次做出 4 个。中心材料为铁锭或对应二阶球材料：

      黑球果

## 先布置战斗顺序

这次由妙蛙草首发。它在数据中 Lv.15 学会催眠粉，因此你的 Lv.20 妙蛙草应能使用；先在摘要确认招式没有被遗忘或替换。

- **第一回合：催眠粉。** 命中后，圈圈熊不能行动，立刻降低翻车风险。
- **第二步：换重泥挽马。** 圈圈熊醒来或需要周转时，由它承伤；若妙蛙草已学寄生种子，可在睡着后先挂上再换。
- **压血阶段：低威力招式优先。** 先用电电虫、坐骑山羊或重泥挽马招式栏中伤害较低的一招试探；火炎狮和肯泰罗只作兜底。
- **黄血即停。** 圈圈熊的血条进黄后，每次攻击前都要观察上一次掉血；接近红血就停止攻击，改睡眠加投球。

大根茎要给真正拥有吸取 HP 招式的队员。它不会让藤鞭、撞击之类招式吸血，也不是给玩家自己吃的恢复药。把它拿在主手，对已经放出来的己方宝可梦右键，选择“给予携带物”；若该宝可梦已有携带物，会先交换出来。

::: warning 元气根的边界
HP 已经变成 0 的宝可梦不能吃元气根。它只回复 80 HP；若队员可能被下一击带走，应先换人，不要赌最后一口血。
:::

## 临场操作

1. **选择战场。** 白天、平地、周围没有苦力怕和深坑时再开战。先清理附近怪物，设床点。
2. **妙蛙草首发。** 选中妙蛙草，准星对准圈圈熊按 `R` 发起战斗；第一回合优先催眠粉。
3. **睡中压血。** 睡眠命中后，若有寄生种子可先挂；再换到招式较轻的队员，一次只攻击一回合并观察血条。第一次打出超过约三分之一 HP 时，马上换低威力招或停手。
4. **用重泥挽马周转。** 圈圈熊醒来、己方脆皮要被击倒时，换重泥挽马吃伤害，再寻找重新催眠或投药的机会。
5. **保住出战成员。** 己方 HP 下降到约三分之一、且对方还能一击击倒时，使用元气根回复 80 HP，或直接换人。不要用昏厥换一次攻击。
6. **投球。** 圈圈熊红血且睡眠后，选择“捕获”，手持沉重球瞄准目标投出。失败后维持睡眠和低血，再连续投；睡醒才补睡眠。
7. **收尾。** 抓到后立刻收回队伍、回基地治疗。没抓到且队伍已残，撤退比继续消耗更划算。

## 为什么沉重球适合它

Cobblemon 的物品提示写明沉重球会按目标重量给出 `x1~x4` 的捕获修正。圈圈熊 `125.8 kg`，正是应该优先使用它的类型；不像藏饱栗鼠那类轻型目标，拿沉重球也几乎没有额外价值。

捕获率仍由多个因素共同决定：球种、当前 HP、异常状态和物种基础捕获率。圈圈熊源码的基础捕获率为 `60`，不是传说级难度，但绝不适合满血裸球。

## 常见失误

- **把大根茎当药吃：** 它是携带物，无法即时回血。
- **让火炎狮或肯泰罗补最后一下：** 当前等级差较大，强力物攻或火系招很可能直接误杀；红血后只投球。
- **元气根太晚使用：** 0 HP 后不能救，需复活草、活力碎片、活力块或治疗机。
- **沉重球投完仍继续硬拼：** 先睡眠、红血、换备用球；全员残血就撤退。
- **忘记保存：** 发现目标、布置好床和背包后先退出到标题或让服务器保存，再开始战斗。
