## 栖息地、遗迹与海湾

1.8 新增了 49 种 Habitat 栖息地结构。这里会出现相对少见的宝可梦，有些还会随日期变化。把远征目标从“随便跑图”改成“找一种特定栖息地”，收获会更稳定。

遗迹和 Shipwreck Cove 船难海湾也很值得去：它们能提供稀有物资与 TM 相关战利品。出发前准备床、食物、方块、备用工具、足够精灵球，并把家设为重生点。

## TM 是队伍成型的关键

1.8 新增 TM Machine。你获得会某个兼容招式的宝可梦后，可以解锁对应 TM 配方；将空白 TM 碟、匹配的属性宝石和所需材料放进机器，就能制作该 TM。

推进建议：

1. 探索时保留属性宝石和空白 TM 碟，不要随便丢弃。
2. 建好 TM Machine 后，优先补足队伍缺的属性招式。
3. 找到遗迹的镀金箱时，重点收集未自然习得的 TM。
4. 用 Move Dex 检查“谁能学某招”，再决定资源给谁。

## Alpha 宝可梦：后期的野外 Boss

Alpha 宝可梦比普通个体更大、更强、更具攻击性，会带领群体出现，还会根据你的队伍变强。它们必定掌握一个 TM 招式。

挑战前至少满足：

- 六只成员的等级接近，且有两只以上不会被对方属性克制。
- 带足回复、基础球以外的高阶球与备用食物。
- 在附近设置床或确保撤退路线。
- 先观察属性、等级和周围群体，不要把它当普通野怪冲上去。

Hopo 树果在 1.8 中会吸引 Alpha，是组织狩猎活动时的好物资。

## 一个自然的终局

官方包没有预设“通关”，可以把终局设为：完成一支有明确打法的六人队、做出稳定 TM 工坊、捕获自己的第一只 Alpha、完成一个地区图鉴目标，再去挑战其他玩家设计的道馆。
