# 牧场方块

牧场方块把你的宝可梦从电脑关联为在基地附近活动的实体。它适合养毛辫羊、蜂女王等有交互或资源产出的宝可梦，也能当作展示与陪伴空间。

```text
木板 木板 木板
木板 电脑 木板
小麦 漏斗 小麦
```

## 使用流程

1. 先围起草地和照明，防怪物攻击。
2. 右键牧场方块，在界面中将自己的宝可梦放入。
3. 它会在牧场范围内活动；需要带回时再从该界面取回。

::: warning 昏厥宝可梦不能放牧
源码会拒绝加入昏厥状态的宝可梦。先把它放进随身队伍，用[治疗仪](/machines/healing-machine)恢复后再放入牧场。
:::

牧场不是物品箱。它保存的是宝可梦与所属玩家、活动范围的关联；更完整的养殖与剪毛说明见[牧场：资源与安全经营](/ranch)。
