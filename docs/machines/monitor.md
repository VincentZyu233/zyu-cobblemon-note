# 数据显示器

<img src="/assets/machines/monitor.png" alt="数据显示器官方方块贴图" style="width: 192px; image-rendering: pixelated;" />

数据显示器不是储物箱，也不会自行刷宝可梦。它是**化石复原三件套的顶部控制台和进度屏幕**。

```text
铁锭 铁锭 铁锭
铜锭 玻璃 铜锭
铁锭 红石火把 铁锭
```

## 正确摆放

把显示器放在[化石分析仪](/machines/fossil-analyzer)正上方；分析仪水平相邻一侧接[复原培养皿](/machines/restoration-tank)。三件接好后，显示器会显示蓝色进度格；完成并生成宝可梦后的短暂保护期则显示绿色满格。

<img src="/assets/machines/monitor-scanning.png" alt="数据显示器扫描进度贴图" style="width: 320px; image-rendering: pixelated;" />

## 单独摆放还能做什么

- 手持**招式学习器**右键：插入一张，屏幕按招式属性变色，同时为插入者解锁该招式的 TM 资料。
- 手持**音乐唱片**右键：插入一张，屏幕显示音乐状态。
- 空手右键：弹出已插入物品。

形成化石结构后，显示器不再接受这些展示物品，专用于显示复原进度。

::: tip 不是“数据显示”面板
它不会显示 TPS、坐标、宝可梦属性，也与 Spark 无关。名称里的“数据”指化石与 TM 的主题交互。
:::
