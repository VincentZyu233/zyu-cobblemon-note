# 化石分析仪

<img src="/assets/machines/fossil-analyzer.png" alt="化石分析仪官方方块贴图" style="width: 192px; image-rendering: pixelated;" />

化石分析仪是化石复原机的“样本槽”。它必须在[数据显示器](/machines/monitor)正下方，并让[复原培养皿](/machines/restoration-tank)贴着它的一侧，才能启动完整机器。

## 操作

1. 按三件套布局摆好，确认显示器在分析仪正上方。
2. 手持化石右键分析仪，放入化石；源码允许最多放入 3 个组成一个有效化石组合。
3. 识别成功后，向培养皿加入有效自然材料，填满后机器自动开始。
4. 显示器分 8 段显示进度，完整过程约 12 分钟。

<img src="/assets/machines/helix-fossil.png" alt="螺旋化石物品贴图" style="width: 96px; image-rendering: pixelated;" />

::: warning 能放进去不等于能复原
源码会根据已放入的化石物品组合查询结果；不构成有效组合时不会启动。把鼠标悬停在 JEI 的化石物品或查看配方，确认它对应单个化石还是需要拼合的化石部件。
:::
