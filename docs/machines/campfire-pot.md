# 营火锅：药品、糖果与球果料理

营火锅不是单独摆在地上的方块，而是一件装到**原版营火**或**灵魂营火**上的锅。装好后，营火就会变成一个 3 x 3 的 Cobblemon 加工台，可以制作药品、经验糖果、麻糬、球果汁和部分料理。

::: tip 最先值得做什么
前期最实用的是药物线：`万能粉 + 蜂蜜瓶 -> 活力碎片`，再用 `活力碎片 x2 + 活力蕾 -> 活力块`。活力块正是[治疗仪](/machines/healing-machine)的核心材料。
:::

## 制作与安装

营火锅一共有红、绿、蓝、粉、黑、白、黄七种颜色；**颜色只取决于球果，功能完全相同**。以绿色为例，工作台配方是：

```text
铜锭   玻璃   铜锭
绿球果        绿球果
铜锭   铜锭   铜锭
```

也就是 `6 铜锭 + 1 玻璃 + 2 个同色球果`。将配方中的绿球果换成其他颜色球果，就能做出对应颜色的锅。

安装步骤：

1. 先在地上放一个已点燃的原版营火或灵魂营火。
2. 主手拿营火锅，对着营火右键，将锅装上去。
3. 空手右键已装锅的营火，打开锅的界面。
4. 要拆锅时，蹲下、主手保持空手，对着营火右键；锅与其中物品会被取出。

::: warning 别往锅上浇水
源码中，水会熄灭营火并把锅和内部物品掉落出来。把它放在室内、屋檐下，或至少别让水流接触营火。
:::

## 界面怎么用

![已安装到营火上的营火锅界面](/assets/machines/campfire-pot-ui.png)

上图就是可用状态的实机界面：左侧 `3 x 3` 是主食材格，右上横排 3 格是**可选树果调味料**，右下大格是成品格。左边的绿色书本按钮会打开配方书；中间锅盖按钮用于开始或暂停烹饪。

多数前期药物配方不需要调味料，按 JEI 摆放主食材即可。球果汁也能在左侧主食材格制作，调味料只用于追加骑乘属性。

放入正确材料后，需要**合上锅盖**才会开始烹饪。可在界面中手动开关；也可以给营火相邻红石信号，源码会将锅盖合上。一次加工默认为 200 游戏刻，约 10 秒。

产物格满了，或放入的材料不能匹配任一配方，进度会停止。因此批量制作时要及时取走产物。

::: details 机器自动化细节
营火锅实现了物品容器接口：漏斗可向食材格输入，顶部输入调味料；成品可被从任意方向抽出。使用桶类材料后留下的空桶，会优先尝试输出到营火正前方相邻的容器，否则掉在地上。
:::

## 实操：给坐骑山羊提升速度

你已经有可用的蓝色营火锅，因此可以直接做**粉色球果汁**。锅的颜色只影响外观，蓝锅同样能做粉色球果汁。

准备：`1 粉色球果 + 1 PP草 + 1 元气根`。这是无序配方，三个材料放进左侧 `3 x 3` 主食材格的任意三个位置即可；右上三个调味格先留空。

1. 放入三种主食材后，右下成品格会显示半透明的粉色球果汁预览。
2. 点击中间的锅盖按钮，让锅盖合上；开始冒泡并出现进度条即表示已开始烹饪。
3. 约 `10` 秒后，从右下成品格取走粉色球果汁。
4. 用 `R` 把你自己的坐骑山羊放到身边，确保它不是处于战斗中。
5. 主手拿粉色球果汁，准星对准这只已放出的山羊右键。成功后球果汁被消耗，山羊获得基础**速度 `+2`、加速度 `-1`** 的骑乘强化。

::: tip 第一次先做无调味版
先做一瓶无调味料的 `速度 +2` 版本，骑上后直接比较跑图手感。坐骑种族本身有速度上限，因此不必一开始就投入稀有树果；物品提示会显示这瓶汁实际携带的属性。
:::

### 想继续堆速度：添加甜味树果

右上 3 个调味格只接受树果。放入带甜味的树果可额外增加速度；例如 `3 个芒芒果` 合计甜味 `45`，会额外给 `+3` 速度，粉色球果汁最终显示为**速度 `+5`、加速度 `-1`**。详情和甜味阈值见[坐骑与移动](/movement#用球果汁强化坐骑)。

## JEI：怎样查询“锅能做什么”

不要靠记忆翻一百多条配方，JEI 更适合反查。

1. 打开背包，搜索 `营火锅` 或 `campfire pot`。
2. 鼠标悬停锅，按 `R` 查看锅本身的合成；按 `U` 查看其作为加工设备的全部用途。
3. 想消耗某种材料时，例如复活草、蜂蜜瓶、球果或经验糖果，对该物品按 `U`。JEI 会直接列出它参与的营火锅配方。
4. 在配方页点击营火锅分类图标，可以在同一分类内连续翻页；搜索 `@cobblemon` 可排除其他模组物品。

::: tip R/U 没反应
到“选项 -> 控制 -> JEI”检查“显示配方”和“显示用途”的按键。默认通常是 `R` 与 `U`，但可能与其他模组的按键冲突。
:::

## 后期还能做什么

Cobblemon 1.8 的营火锅配方超过一百条，主要可分为：

- **药品与异常状态治疗**：伤药、好伤药、厉害伤药、解毒药、灼伤药、解冻药、解麻药、清醒药、元气碎片和活力块。
- **经验与能力培养**：不同规格经验糖果，以及六类能力糖果和麻糬。
- **球果与骑乘补给**：七色球果汁；部分配方会读取调味料，赋予骑乘相关加成。
- **食物与甜点**：三明治、咖喱、麻辣萨达、可丽饼、蛋糕、糖渍果实等。

配方会随整合包版本和数据包改变，因此“要做某个物品”时永远以本地 JEI 显示为准。
