# 电脑

电脑是你的**个人宝可梦盒子终端**：把队伍中的宝可梦调入盒子、从盒子换入队伍、查看状态和整理编队。它不存放铁锭、精灵球等物品，也不是全服共享仓库。

```text
铁锭  玻璃  铁锭
铁锭  铜锭  铁锭
平滑石头 铜锭 平滑石头
```

## 怎么用

1. 放下电脑并右键。
2. 在队伍与电脑盒子之间移动宝可梦。
3. 离开前确认首发 6 只，野外按 `R` 放出的始终是当前队伍中选中的成员。

::: warning 多人服的归属
源码中电脑通过玩家 UUID 连接个人 PC 存储。因此朋友右键同一台电脑，打开的是**朋友自己的盒子**，不会看到或取走你的宝可梦。
:::

需要把宝可梦给朋友时，应走[交换、赠送与换主](/trading)的流程；不要指望把它塞进电脑共享。
