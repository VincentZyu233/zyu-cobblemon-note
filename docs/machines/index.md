# 设备与机器专题

Cobblemon 的设备不是都能单独工作。先区分“独立设备”和“化石复原三件套”，基地就不会摆到一半卡住。

| 设备 | 主要用途 | 能否单独使用 |
| --- | --- | --- |
| [治疗仪](/machines/healing-machine) | 治疗、复活随身队伍 | 可以 |
| [电脑](/machines/pc) | 管理自己的宝可梦盒子 | 可以 |
| [牧场方块](/machines/pasture) | 放出、管理和互动宝可梦 | 可以 |
| [营火锅](/machines/campfire-pot) | 制作药品、糖果、球果汁与料理 | 需装在营火上 |
| [招式学习器机](/machines/tm-machine) | 用空白学习器制作招式学习器 | 可以 |
| [数据显示器](/machines/monitor) | 化石机进度屏幕与 TM/唱片展示 | 仅展示；复原需三件套 |
| [化石分析仪](/machines/fossil-analyzer) | 放入并识别化石 | 需接三件套 |
| [复原培养皿](/machines/restoration-tank) | 注入自然材料、孵化化石宝可梦 | 需接三件套 |

::: tip 推荐建造顺序
先做治疗仪，再做电脑；有稳定基地后摆牧场。招式学习器机和化石三件套都属于中期项目，材料到位再做，不必抢在第一台治疗仪之前。
:::

## 化石复原三件套

```text
      数据显示器
          │ 正上方
      化石分析仪 ── 复原培养皿
```

源码要求显示器**直接在分析仪上方**，复原培养皿的底部与分析仪**相邻的任一水平侧面**相接。形成结构后，向分析仪放化石、向培养皿加入自然材料；识别出有效化石且培养皿达到所需 DNA 后，机器自动开始 12 分钟复原。

::: warning 不要把三件套当三个独立机器
显示器单独可插唱片或 TM，分析仪和培养皿单独摆着却不会复原化石。三者正确接触后才形成一台机器。
:::
