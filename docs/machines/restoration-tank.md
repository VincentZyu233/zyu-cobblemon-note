# 复原培养皿

复原培养皿是化石机的 DNA/自然材料槽。放下时是两格高结构；其**底部**必须与化石分析仪的北、南、东或西侧相邻。

## 它做什么

分析仪确定要复原的化石，培养皿接收带有“自然材料值”的物品。源码要求累计达到 `128` 点后，若分析仪已识别有效化石，机器自动开始；复原耗时约 `12` 分钟。

```text
显示器
分析仪 ─ 培养皿底部
```

## 使用建议

1. 先把三件套摆好，再往分析仪放化石。
2. 对培养皿右键加入自然材料；接受哪些物品及其数值，以 JEI 提示为准。
3. 满槽后别拆机器。完成时会生成对应的化石宝可梦，并有约 5 分钟的归属保护时间。

::: warning 培养皿不是水桶机器
这里填的不是普通水，也不是治疗仪的活力块；它读取 Cobblemon 的“自然材料”数据。无效物品不会增加槽内数值。
:::
