# 招式学习器机

招式学习器机用于制作招式学习器（TM），不是让宝可梦直接学习招式的电脑。先在机器中选定要制作的招式，再投入空白学习器和该招式要求的材料。

```text
铁锭 遮光玻璃 铁锭
铜锭 红石粉   铜锭
```

## 怎么用

1. 放下机器并右键，选定已经解锁的招式。
2. 放入 `空白学习器` 与界面要求的材料；机器保存这些槽位，退出界面不会丢失。
3. 取走产出的招式学习器，再对队伍中对应宝可梦使用或在其摘要界面操作学习。

源码中机器有空白学习器槽、至多 3 个材料槽和产物槽；接红石信号后可在条件满足时自动连续制作，适合后期材料批量加工。

::: tip 和数据显示器的关系
把一张现成 TM 插入[数据显示器](/machines/monitor)，会解锁该招式的 TM 资料；真正消耗空白 TM 和材料进行制造的是这台机器。
:::
