# 宝可梦钓竿与鱼饵

Cobblemon 1.8 已经实现完整钓鱼：你能在水面钓到原版战利品，也可能把一只野生宝可梦拉到岸边。后者不会自动收服，仍要照常战斗、压血和丢精灵球。

::: tip 最短操作
`装鱼饵 -> 对水面右键抛竿 -> 等波纹/提示音 -> 再右键收线 -> 战斗收服`。
:::

## 先做一根宝可梦钓竿

在锻造台放入：

```text
宝可梦钓竿锻造模板 + 原版钓鱼竿 + 任意一种精灵球
```

最朴素的组合是“模板 + 原版钓鱼竿 + 精灵球”，产物就是宝可梦钓竿。把最后一格换成超级球、诱饵球、捕网球等，会做成相应外观的钓竿。

模板可在钓鱼宝藏与部分海边/海洋结构箱中找到。拿到第一张后可在工作台复制：`5 金锭 + 1 海晶碎片 + 1 模板 -> 2 模板`。

::: warning 普通钓鱼竿不能装 Cobblemon 鱼饵
原版钓鱼竿只走原版钓鱼表。必须经过锻造台变成“宝可梦钓竿”，背包中对它右键装饵的功能才会出现。
:::

## 什么东西能当鱼饵

物品提示中有蓝色 **“鱼饵”** 分类的作物或树果，可以直接装到钓竿。它们不是放进水里，也不是对水面右键使用。

还有另一类叫 **“诱饵调料”**。它不能直接挂钩，需要装入[营火锅](/machines/campfire-pot)，制作成“宝诱饵”后才可使用：

```text
蜂蜜瓶 + 任意蘑菇 + 小麦 -> 4 个宝诱饵
```

将带诱饵效果的作物放进营火锅右上三个调味料格，宝诱饵会继承它们的效果，例如更快上钩、偏向某属性或蛋群、提高隐藏特性、头目、发光、证章等出现机会。成品悬停提示会列出实际继承到的“诱饵信息”。

::: info 不要只看物品名字
“鱼饵”是能直接上钩的物品分类；“诱饵调料”是料理配料分类。两者名称很像，但操作完全不同。拿不准时，把物品放到鼠标上，对钓竿右键：能装进去才是直接鱼饵。
:::

## 装饵、抛竿、收线

### 1. 最可靠的装饵方法：背包右键

1. 打开背包，把宝可梦钓竿放在任意格子。
2. 用鼠标拿起一组标为“鱼饵”的物品。
3. 对背包里的宝可梦钓竿按右键。
4. 钓竿提示出现 `饵料：物品名 x 数量`，即装载成功。

源码会把该种饵料存进钓竿本身；相同饵料可继续堆入。空手对已装饵钓竿右键可取回饵料。

### 2. 到水边实钓

1. 手持已装饵的宝可梦钓竿，站在水边，对水面右键抛竿。
2. 观察浮标。出现水花、向浮标靠近的波纹和提示音时立刻再右键。
3. 成功钓到宝可梦时，它会被生成在浮标附近并被拉向你前方；立刻丢出队伍宝可梦开战。
4. 按普通流程削血、上异常状态，再用合适精灵球收服。

成功钓出**宝可梦**才会消耗钓竿中 `1` 份鱼饵；空竿或钓到原版物品不会消耗它。

## 怎么提高成功体验

- 优先选开阔水面，不要把浮标丢在岸边、睡莲、方块边缘或瀑布里。
- 原版附魔仍会被读取：`饵钓`缩短等待，`海之眷顾`影响原版战利品部分。
- 想要指定类型或稀有特征，不要无脑消耗稀有树果。先做少量带调味效果的宝诱饵，看看成品提示的百分比，再批量制作。
- 钓上来的是野生实体，跑掉、被误杀都和陆地遇怪一样处理；钓竿不是“一键收服道具”。

## 你现在值得尝试吗

值得，但把它视作一种补充探索方式，不是高效刷指定宝可梦的替代品。前期先用库存富余、可再种植的作物做饵，试着在河流、海边和湖泊各钓几次；遇到想要的水系再用战斗和精灵球处理。
