# 多人服务器玩法

## 适合小服的三条主线

| 主线 | 规则建议 | 奖励建议 |
| --- | --- | --- |
| 图鉴季 | 每周一个地区或属性主题 | 展示墙位置、命名权、稀有球材料 |
| 道馆季 | 每人设计一种属性或天气主题队伍 | 徽章、挑战记录、冠军称号 |
| 远征季 | 组队寻找栖息地、遗迹、海湾或 Alpha | 战利品按出发前约定分配 |

这比“谁先拿到最强宝可梦”更适合朋友服，因为每个人都有稳定可做的事。

## 建筑与资源约定

建议出生点放一块公告牌，写清楚三条规则：不动他人球果园和仓库；稀有结构先共同探索再分配；重要战利品先截图/说明再决定归属。这个官方包没有把领地保护作为核心玩法，信任规则和定期备份尤其重要。

## 服主的小建议

- 对外开放前先启用白名单，只邀请确认过的玩家。
- 升级 Cobblemon 或替换数据包前，备份整个 `world` 目录。
- 客户端要从同一个 `.mrpack` 导入；不要让玩家自行增删会影响联机协议的模组。
- 有人掉帧时，先关闭光影、调低视距，再排查模组，不要急着删服务端核心模组。

## 可直接组织的第一场活动

“球果与新伙伴远征”：每人从基地出发 30 分钟，目标是带回两种没见过的宝可梦与三种颜色球果。回基地后用图鉴记录展示成果，再一起决定谁的区域适合建球果园。这活动不需要高等级队伍，也能让新玩家马上融入。
