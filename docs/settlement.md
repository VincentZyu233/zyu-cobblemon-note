# 据点与资源循环

一座好据点不是把所有机器一次摆齐，而是让每次外出都能带回下一次出门需要的东西。这个包最实用的循环是：探索带回球果、矿物、树果与战利品，回家补球、整理队伍、恢复状态，再带着更合适的队伍去更远的地方。

## 据点先分成五个区

| 区域 | 第一批该放什么 | 为什么优先 |
| --- | --- | --- |
| 生存区 | 床、食物、熔炉、普通储物 | 保证夜间与远征失败后能立刻恢复 |
| 捕获区 | 球果箱、铜铁金、精灵球成品箱 | 做球时不会翻遍所有箱子 |
| 队伍区 | 治疗机、PC、常用回复物 | 出门前 10 秒内完成补给与换队 |
| 农业区 | 球果园、后续树果与小麦 | 把球和回复材料变成可再生资源 |
| 展示区 | 牧场、化石、奖杯/图鉴墙 | 给长期收集和多人活动留出空间 |

先保证前 3 个区可用。牧场、化石复活和大型展示适合等资源稳定后再建，避免开局把铜铁全花在好看但不提高探索效率的设施上。

## 队伍区的三个核心设施

### 治疗机：每次出门前的最后一站

治疗机的价值不在于“省药”，而在于让受伤、濒死的队伍不必专门回到床边等待或临时换人。把它放在出口与 PC 的中间，每次进出顺手使用即可。当前 1.8 配方是 `3 铜锭 + 4 铁锭 + 1 红石粉 + 1 活力块`；活力块由营火锅的 `2 活力碎片 + 1 活力蕾` 制作。活力碎片则是 `复活草 -> 万能粉` 后，再将 `万能粉 + 蜂蜜瓶` 放入营火锅制成。它会自动充电，无需红石供电，但默认从空到满约 15 分钟；详细药物路线见[培养页的回复与强化](/training#回复复活与变强的物品)。

### PC：队伍容量以外的真正仓库

PC 能访问宝可梦存储系统。队伍满员时，新捕获的宝可梦会自动进入存储；官方资料给出的默认容量是 30 箱，并支持按名字、等级、属性、图鉴编号或性别排序。

这意味着前期遇到“现在用不上但以后想研究”的宝可梦可以先抓，不需要为了留出队伍位置把它放掉。建议按用途命名几个箱子，例如“待培养”“交换/展示”“树果与坐骑候选”，后期翻找会轻松很多。

### 牧场：展示和公共防卫，不是练级机

牧场由 PC 延伸而来，可把最多 16 只存储中的宝可梦放入周围区域；它们可以像野外或放出的宝可梦一样互动。界面中的剑图标能切换是否自动攻击敌对生物，全部召回按钮可快速收回；破坏牧场方块也会自动召回。

所以牧场适合建在有围栏、照明、空地的安全区，作为展示、拍照、朋友参观和基地周边防卫用途。它不是让 16 只宝可梦自动获得经验的设施，不要把它当作挂机练级方案。

## 野外资源的优先级

### 1. 每次都带回：球果、种子、铜铁金

球果决定精灵球产量，种子决定能否摆脱野外采集；铜、铁、金则直接制约基础球、高级球和 PC 等设施。第一次见到新颜色球果时，优先留种而不是马上全部制成球。详细采集逻辑见 [球果章节](/getting-started#第一项专属资源球果)。

### 2. 中期囤积：属性宝石与空白 TM 碟

1.8 的 TM Machine 以属性宝石和材料制作 TM。即使当前没有适配队员，也要按属性分箱保留宝石与空白碟，等队伍定位确定后再用 Move Dex 和 TM Machine 消耗它们。把珍贵资源转成当前队伍用不到的 TM，通常是最早期的浪费之一。

### 3. 发现稀有矿物：先记坐标，再按需求采

紫水晶洞、恶地金矿、高山铁矿和深层钻石都值得记录坐标。它们的具体层数、可再生机制和 Cobblemon 用途见[资源专题](/resources/amethyst)。

### 4. 看见就记录：Tumblestone 与遗迹战利品

源码中的古代球配方会使用普通、天空或黑色 Tumblestone；遗迹战利品表也会产出它们。你不必为了它们专门放弃当前目标，但发现时应记下位置并留一组，因为它们后期能打开古代球路线。

### 5. 远征项目：化石

化石结构里会有可疑沙子或可疑砂砾，拿刷子处理才有机会得到化石；化石需放进完整的 Resurrection Machine 复活。它们是收集目标而非开荒刚需。

如果要找特定伙伴再选目标结构会更高效：例如 Old Amber 对应化石翼龙，常见于橡树/云杉化石树；Helix Fossil 对应菊石兽，Sandy Den 是保证含有它的结构之一。发现化石后先收好并标记位置，等家里有空间和材料，按游戏内提示搭好完整复活机再处理。

::: tip 小服资源约定
建议公共设施只放治疗机、公共 PC 区和展示牧场；个人的球果、TM 宝石、化石和高阶球仍各自保管。这样既能降低新玩家的进入门槛，又不会让稀有资源归属不清。
:::

## 一次 20 分钟远征的背包清单

| 物品 | 用途 |
| --- | --- |
| 床、食物、火把、方块 | 原版生存安全与临时返程点 |
| 多种精灵球 | 不让一个好目标因球种不合适而错过 |
| 备用工具与剪刀 | 采矿、处理植被、收集特殊资源 |
| 刷子 | 发现可疑沙子/砂砾时立刻检查化石 |
| 空白地图或坐标记录 | 标记球果林、遗迹、化石结构和栖息地 |

回家后按“先补球果与矿物，后整理 PC，最后决定下一次队伍”处理战利品。这个顺序能避免一箱资源放到忘记，也能让每次远征都有明确的下一步。
