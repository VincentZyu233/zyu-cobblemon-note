# 按键、物资与资料

## 关键按键

| 操作 | 建议 |
| --- | --- |
| 放出、收回、互动 | 默认重点关注 `R`；以控制设置中 Cobblemon 分类显示为准 |
| 切换队伍成员 | 默认上、下方向键；按实际控制设置中的 Cobblemon 绑定为准 |
| 配方查询 | EMI/JEI 搜索物品名称，点击查看合成与用途 |
| 地图 | Xaero 小地图与世界地图已经随整合包提供，按键可在控制设置调整 |

## 指定放出的宝可梦

Cobblemon 会记录一个“当前选中的队伍栏位”。默认按上、下方向键移动这个选中位置，队伍 HUD 上带高亮边框的就是下一次会被放出的宝可梦；按 `R` 则放出或收回它。

1. 按上、下方向键，切到目标宝可梦。
2. 准星对准空地或地面，按一下并松开 `R`，它会被放出来跟随你。
3. 收回时保持选中同一只，再按一次 `R`。

准星对准野生宝可梦时按 `R`，当前选中者会向它发起战斗；想单纯让它跟随，先对空地按 `R`。在“选项 -> 控制 -> Cobblemon”中，三个默认键位名称分别是“上移同行宝可梦”“下移同行宝可梦”和“扔出选择的宝可梦”。

## 长期保留的物资

| 物资 | 为什么不要乱丢 |
| --- | --- |
| 多色球果与种子 | 精灵球体系和球果园的核心 |
| 铜、铁、金、钻石 | 对应不同阶级的精灵球与设施 |
| 属性宝石 | 制作 TM 的核心材料 |
| 空白 TM 碟 | TM Machine 的消耗品 |
| 特殊树果 | 回复、诱饵与特定玩法材料 |
| 遗迹/海湾战利品 | 可能补齐稀有 TM 或探索资源 |
